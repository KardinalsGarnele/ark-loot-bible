# Mission

The ARK Loot Bible is a canonical, source-verified database of official ARK: Survival Ascended content, connecting items, blueprints, loot, creatures, bosses, maps, and gameplay systems through a single normalized data model.

## Product promise

Players should find useful answers quickly without seeing the complexity required to produce them.

## North-star principles

- Simple for players. Powerful by design.
- Build the platform. Everything else is an interface.
- Model the game. Not the spreadsheet.
- Build it once. Build it right.
