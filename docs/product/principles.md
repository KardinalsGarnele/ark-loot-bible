# Project Principles

## Source first
Canonical facts require traceable evidence.

## Canonical only
Unknown values remain unknown and are marked `NEEDS_VERIFICATION`.

## Normalize once
A fact is stored once and referenced wherever it is needed.

## Export everywhere
Website, API, bot, app, JSON, SQLite, PostgreSQL, and spreadsheets consume the same canonical source.

## Version everything
Schema, data, imports, and exports are versioned.

## Never lose information
Changes are historical records, not destructive overwrites.

## Stable identity
Identifiers never change and are never reused.

## User experience matters
The database may be complex; the interface must not be.
