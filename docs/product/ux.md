# UX Principles

## Answers first
Show the likely answer before technical detail.

## Details on demand
Use tabs, expandable sections, filters, and advanced views.

## Search first
Users should be able to search creatures, items, blueprints, loot sources, bosses, maps, and notes from one place.

## No dead ends
Every page should expose meaningful relationships to adjacent knowledge.

## Progressive complexity
Casual players see essentials. Experienced players can reveal routes, comparisons, probabilities, evidence, and developer data.

## Consistent page anatomy
1. Identity and summary
2. Quick facts
3. Primary task content
4. Related entities
5. Interactive tools
6. Evidence and history
7. Advanced technical data

## Smart maps
Map layers should be independently switchable: creature spawns, loot, caves, resources, artifacts, notes, bosses, and other relevant systems.
