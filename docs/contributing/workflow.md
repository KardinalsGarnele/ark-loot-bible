# Contribution Workflow

1. Register or identify the source.
2. Import into staging.
3. Validate required fields and references.
4. Resolve stable IDs.
5. Compare against canonical data.
6. Record evidence and verification status.
7. Run relationship and export tests.
8. Review the generated change set.
9. Publish through a versioned release.

Direct manual edits to generated exports are not accepted.
