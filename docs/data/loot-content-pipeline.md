# Loot Content Pipeline

The pipeline imports Loot Source -> Loot Set -> Loot Entry packages into the
existing normalized loot domain.

Every numeric gameplay value is nullable. Missing weights, roll counts,
quantities, blueprint chances, quality ranges, respawn values and coordinates
must remain null until evidence supports them.

The included The Island package is structural reference data, not a verified
claim that the Rex Saddle Blueprint drops from a specific crate.
