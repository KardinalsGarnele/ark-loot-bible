# Official Content Pipeline

Official content is delivered as versioned manifests. A manifest registers its source, validates every record, and may be executed as a dry-run before commit.

The first package contains the verified identity of The Island and eight empty structural collections. Empty means the platform knows the category exists, not that its child data has been verified. Regions, spawns, caves, loot, artifacts, bosses, explorer notes, and resources require dedicated source packages before their records can be promoted.
