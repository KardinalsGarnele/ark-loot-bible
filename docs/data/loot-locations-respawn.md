# Loot Locations & Respawn

Loot source location types:

- fixed point;
- region;
- route;
- random world;
- moving;
- unknown.

ARK map coordinates are stored on a 0–100 latitude/longitude scale. Fixed points
require both coordinates. Region-only records can omit coordinates entirely.

Respawn profiles support fixed times, ranges, conditions, global pools and
unknown behavior. Missing timings remain null.
