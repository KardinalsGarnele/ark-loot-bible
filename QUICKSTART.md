# Quick start

## Docker (easiest)

```bash
docker compose up --build
```

Open:

- Home: http://127.0.0.1:8000
- Blueprint Finder: http://127.0.0.1:8000/blueprint-finder
- Loot Matrix: http://127.0.0.1:8000/loot-matrix
- Coverage: http://127.0.0.1:8000/coverage
- API docs: http://127.0.0.1:8000/docs

## Windows without Docker

Double-click `start.bat`, then open http://127.0.0.1:8000.

## Linux/macOS without Docker

```bash
./start.sh
```

The included database contains only the current structural/demo records. They are visibly marked as unverified where applicable.
